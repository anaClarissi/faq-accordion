## 📖 About The Project

O projeto consiste em uma página de **FAQ Accordion**, onde o usuário pode expandir e recolher perguntas frequentes de forma intuitiva e elegante.

Esse desafio foi excelente para praticar:

* Estruturação semântica
* Responsividade
* Estados interativos
* Uso avançado de CSS
* Componentes acessíveis com `<details>` e `<summary>`

---

## ✨ Features

✅ Accordion funcional sem JavaScript
✅ Design moderno inspirado no Frontend Mentor
✅ Layout totalmente responsivo
✅ Efeitos hover suaves
✅ Ícones dinâmicos de abrir/fechar
✅ Organização com variáveis CSS
✅ Estrutura limpa e semântica

## 🧠 What I Learned

Durante esse projeto pratiquei conceitos importantes como:

* Uso semântico de `<details>` e `<summary>`
* Controle visual de estados usando CSS
* Criação de accordions acessíveis
* Responsividade para diferentes dispositivos
* Organização do CSS com variáveis
* Manipulação de pseudo-classes como `:hover` e `:open`
* Estruturação visual moderna com Flexbox
